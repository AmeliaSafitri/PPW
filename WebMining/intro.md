**Pencarian Web (Web Search)** adalah proses menemukan informasi yang relevan dari internet berdasarkan kata kunci atau query yang diberikan oleh pengguna. Sistem pencarian akan memproses query, mencari informasi yang sesuai, kemudian menampilkan hasil berdasarkan tingkat relevansinya. Contohnya adalah ketika pengguna mencari artikel, berita, atau jurnal melalui mesin pencari.

**Penambangan Web (Web Mining)** adalah proses mengambil dan menganalisis data dari web untuk menemukan informasi, pola, dan pengetahuan yang bermanfaat. Web mining dapat menggunakan teknik seperti data mining, machine learning, dan Natural Language Processing (NLP). Contohnya adalah menganalisis data berita untuk mengetahui topik yang sedang populer atau sentimen masyarakat terhadap suatu isu.

**Pengantar Pencarian dan Penambangan Web**

Perkembangan internet menyebabkan jumlah informasi yang tersedia di web semakin besar. Kondisi tersebut membuat pengguna membutuhkan cara yang efektif untuk menemukan informasi yang sesuai dan mengolahnya menjadi pengetahuan.

Pencarian web berfokus pada menemukan informasi yang relevan, sedangkan penambangan web berfokus pada menganalisis data web untuk menemukan pola atau pengetahuan baru. Keduanya dapat digunakan bersama, misalnya mencari dan mengumpulkan artikel berita kemudian menganalisis isi artikel tersebut untuk mendapatkan informasi tertentu.

Secara sederhana:
- Web Search → mencari informasi yang relevan
- Web Mining → menganalisis data untuk menemukan pengetahuan
